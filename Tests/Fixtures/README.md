# Wasser-Regression

`forever-water.png` ist ein unveränderter 96 × 96 Pixel großer Ausschnitt bei (2674, 834) aus dem vom Benutzer bereitgestellten Screenshot `WoWScrnShot_111426_192542.jpg`. Der Bereich enthält Wasser ohne Bobber. Die reine Graustufen-Suche lieferte dort mit einer gedrehten/verformten Vorlage einen Fehlertreffer über 80 %. Der Test prüft, dass die zusätzliche Körperfarbprüfung diesen Ausschnitt bei einer Mindestübereinstimmung von 70 % verwirft.
